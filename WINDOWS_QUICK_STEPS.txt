  → Download: https://maven.apache.org/download.cgi
  → Extract to: C:\Program Files\apache-maven-3.9.x

☐ Node.js 20+ (comes with npm)
  → Download: https://nodejs.org/
  → Run installer
  → Verify: node -version && npm -version

================================================================================
STEP 2: SETUP DATABASE (First time only)
================================================================================
1. Open Command Prompt (cmd.exe) - NOT PowerShell
2. Login to MySQL:
   cmd> mysql -u root -p
   (Enter your MySQL password)

3. Create database:
   mysql> CREATE DATABASE earthcare_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   mysql> EXIT;

4. Load sample data:
   cmd> mysql -u root -p earthcare_db < backend/src/main/resources/db/init.sql
   (Enter your MySQL password)
   (Wait for completion)

5. Verify:
   cmd> mysql -u root -p earthcare_db
   mysql> SHOW TABLES;
   (Should show 23 tables)
   mysql> EXIT;

================================================================================
TROUBLESHOOTING
================================================================================

PROBLEM: "mvn is not recognized"
SOLUTION: Maven not installed or PATH not updated
  → Install Maven (see STEP 1)
  → Add to PATH (see WINDOWS_SETUP.md)
  → Restart PowerShell
  → Test: mvn -version

PROBLEM: "java is not recognized"
SOLUTION: Java not installed or PATH not updated
  → Install Java 21 (see STEP 1)
  → Restart PowerShell
  → Test: java -version

PROBLEM: "mysql: command not found"
SOLUTION: Use Command Prompt (cmd.exe) not PowerShell
  → Open Command Prompt
  → mysql -u root -p

PROBLEM: "Port 8080 already in use"
SOLUTION: Kill process using port 8080
  → PowerShell: Get-Process | Where-Object {$_.ProcessName -like "*java*"} | Stop-Process

PROBLEM: "Cannot connect to database"
SOLUTION: MySQL not running or wrong credentials
  → Check: Get-Service MySQL80 (should be Running)
  → Start: Start-Service MySQL80
  → Verify credentials in application.properties

PROBLEM: "npm packages not installed"
SOLUTION: Reinstall node_modules
  → cd frontend
  → rm -r node_modules package-lock.json
  → npm install

================================================================================
DATABASE SETUP (Use Command Prompt - cmd.exe)
================================================================================

COMMAND 1: Create Database
----
mysql -u root -p
----
Then type your MySQL password and paste:

CREATE DATABASE earthcare_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
EXIT;

COMMAND 2: Load Sample Data
----
mysql -u root -p earthcare_db < backend/src/main/resources/db/init.sql
----
Enter your MySQL password and wait for completion.

COMMAND 3: Verify Database
----
mysql -u root -p earthcare_db
SHOW TABLES;
EXIT;
----
Should show 23 tables.

================================================================================
BACKEND SETUP & RUN (Use PowerShell)
================================================================================

COMMAND 1: Navigate to Backend
----
cd C:\Users\Niharika\Desktop\AD\backend
----

COMMAND 2: Update Config File
----
notepad src\main\resources\application.properties
----
Find: spring.datasource.password=root
Change to your MySQL password
Save and close

COMMAND 3: Build Backend (First Time - Takes 3-5 minutes)
----
mvn clean install
----
Wait for: "BUILD SUCCESS"

COMMAND 4: Run Backend
----
mvn spring-boot:run
----
Wait for: "Started EarthCareApplication in X.XXX seconds"

Keep this window open!

================================================================================
IF PROBLEMS - QUICK FIXES
================================================================================

Maven Not Found:
1. Restart computer (not just PowerShell)
2. Test: mvn -version
3. If still fails, install Maven (see WINDOWS_SETUP.md)

Java Not Found:
1. Restart computer (not just PowerShell)
2. Test: java -version
3. If still fails, install Java 21 (see WINDOWS_SETUP.md)

MySQL Commands Not Working:
1. Use Command Prompt (cmd.exe) instead of PowerShell
2. For PowerShell: mysql -u root -p (then enter password)

Port 8080 Already In Use:
1. Kill Java process:
   Get-Process | Where-Object {$_.ProcessName -eq "java"} | Stop-Process -Force

npm install hangs:
1. Stop with Ctrl+C
2. Clear cache: npm cache clean --force
3. Try again: npm install
